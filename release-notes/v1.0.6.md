# TorrentToDDL v1.0.6

Public GitHub release with the new TorrentToDDL logo.

- Adaptive launcher icon and Android 13+ themed icon support.
- Matching in-app branding and gateway notification icon.
- Gateway stays on while the app is visible, including for cached torrents.
- Background idle shutdown and active-transfer protection.
- Separate real-byte torrent-cache and save-to-device progress.

Download TorrentToDDL.apk directly under Assets. This is a non-debuggable
release build using the existing persistent signing identity, preserving
updates from v1.0.5. SHA256SUMS and the public certificate report are included.

Use LAN links on trusted networks. Device-specific notification behavior,
torrent swarms and battery consumption still require Android device testing.
